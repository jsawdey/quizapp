# Open Trivia Database fixtures

Real responses from [Open Trivia Database](https://opentdb.com), saved by
`python3 tool/capture_opentdb.py` on the date in `manifest.json`. The
manifest records each file's request URL and HTTP status (code 5 comes with
HTTP 429). Session tokens are replaced with the placeholder it names.
